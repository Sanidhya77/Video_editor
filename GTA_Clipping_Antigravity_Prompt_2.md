# Antigravity prompt 2 — GTA clipping campaign pilot and automation

Copy the task below into Antigravity while the shared GTA_clipping workspace is open.

## Task

Extend the existing Windows-first GTA clipping MVP to support a small, measurable paid-campaign pilot. Read AGENTS.md, CURRENT_RUN.md, README.md, the relevant source modules, and the existing research template first. Preserve the current import, analyze, preview and render entry points. Keep original footage, working media, models and exports in the configurable local data directory outside OneDrive. Use lightweight local files for campaign and results tracking. Update CURRENT_RUN.md with exact commands, results, verified sources, blockers and the next action.

### 1. Research the available campaigns and editing formats

- Use Northbridge Search and Northbridge's public-page reader first if exposed. Record which search and page reads actually worked. Check a source's current campaign page and terms. Use another permitted public research route if Northbridge cannot read a page. Treat indexed snippets as leads. Use a small number of relevant pages and avoid screenshots unless necessary to see an edit.
- Start with the standalone Content Rewards campaign below, then look for one active gaming offer on Content Rewards and one on Vyro or another marketplace with readable official terms. Gaming only for the paid pilot. Check post/account eligibility, audience geography, funding, rate and currency per platform, minimum payout, maximum per post, fee, deadline, payout and withdrawal terms, approved source footage and music, sponsor disclosures, preapproval, and repeat-post or cross-post restrictions. Record exact links and check times. Mark login-only details as unverified. Choose a campaign only after the user can confirm account eligibility, payout setup and appropriate rights. If none qualifies, report it and use dummy campaign data for local testing.
- Study 12 public GTA V, GTA Online or adjacent gaming Shorts/Reels as a starting sample. Include ordinary and high-view examples from the same creators where possible, across mechanic experiments, stunts/escapes, and contextual reactions. Record URL, format, duration, first visible or audible hook, visual crop, caption design, time to payoff, visible metrics and observation date. Separate directly watched footage from titles or metadata. Mark Instagram samples unavailable if you cannot see them. Split the blank research template from examples and label placeholders as synthetic. Do not treat its existing example row as observed evidence without verification.
- Create a first-batch edit recipe from observations. Test a short question opening against immediate action on different comparable clips. Keep each post understandable on its own. Use accurate phrase captions (two lines at most), portrait-friendly visual focus, and the crop or fit layout that preserves the action and relevant HUD. Use 15–35 seconds as a starting range; adjust to fit the actual payoff. Treat music, overlays and calls to action as campaign-controlled fields. Log the hypothesis and keep untested assumptions visible.
- Verify the real-footage workflow with a creator-supplied or otherwise authorized 10–20 minute recording if one is available. Compare the tool's top picks against a short list of hand-marked moments and log misses, false positives, how much editing each export needed, and the elapsed time. Include a visual-only candidate and a speech-based candidate if the recording supports both. Use the synthetic fixtures if real footage isn't available, and label their results accordingly.

### 2. Build the local workflow

- Add a small campaign brief record and a clip-to-campaign export checklist. Store platform-specific pay rates, min/max thresholds, creator fees, remaining budget and when verified, allowed platforms, submission window, required media/disclosure, rights status and campaign link. Allow manual entry or an explicit import of a local brief. Use manual entry for data visible only in a signed-in dashboard.
- Export a ready-to-review package per clip: MP4, caption text, subtitle file if present, sponsor disclosure if required, creator/source credit, campaign link, and a short instructions file for the operator. Preserve rendering and content-selection settings. A campaign can require draft approval before posting. Keep review, draft approval, public post, link submission, approval, settled payout and collected payout as separate states. A private upload or an upload still processing is not a campaign submission.
- When the operator logs a public post URL and its actual publication timestamp, show the campaign's submission deadline and the action needed. Content Rewards currently documents a 30-minute window for normal submissions on connected, verified public accounts. Make the window configurable and show overdue status. Require one unique post URL per submission and guard against duplicate records across campaigns. Track status and rejection reasons entered by the user.
- Calculate a conditional payout estimate using eligible/verified views, the rule for the minimum, the rate, maximum, and the applicable fee. Keep public views, eligible views, estimated net, settled amount and received amount distinct. At minimum support CPM; preserve manual notes for other payout models without calculating their payouts unless their actual rules are known. Include editing minutes and net received per hour. Use the local mock example of USD 0.70 per 1,000 views, USD 2 gross minimum, USD 35 gross cap and 10% fee. Expected conditional net: 1,000 eligible views = USD 0, 10,000 = USD 6.30, 50,000 or more = USD 31.50, assuming approval and funding. Validate all input values and avoid floating-point currency errors.
- Add simple scorecard fields for 24-hour and 7-day checks. YouTube: Stayed to watch, average percentage viewed and engaged views. Instagram: record available account metrics, for example views and shares, and the date. Keep campaign-verified views separate from each platform's displayed counts. Reporting should work from local inputs, with optional authorized metrics ingestion as a later step.

### 3. Stage approved publishing automation

- Phase A: implement the local preparation and campaign tracking above. The operator publishes in the platform's own UI and pastes the public link into the campaign submission form. Use the open campaign page as a handoff, with a countdown; never use the countdown as evidence that submission occurred.
- Phase B: document or mock an opt-in YouTube upload adapter using Google OAuth and explicit private visibility. Add an Instagram professional-account publishing adapter only after verifying access scopes and the applicable approval requirements. Keep separate publish targets and receipts, and design retries to avoid duplicate posts after an uncertain response. Add TikTok to the manual handoff where lawfully available; its Direct Post guidelines exclude an internal tool for managed accounts.
- Use documented, authorized APIs for any integration. Keep direct campaign submission manual unless a documented supported API is verified. During this pilot use local fixtures for posting or external state changes and leave those actions to the operator. Keep account credentials, access tokens and identity information outside synced files and logs.

### Acceptance checks

- Run the existing tests, report results, and add coverage for threshold/cap/fee boundaries, duplicate post URL, missing/unverified views, a draft-approval case, and an expired submission window.
- Produce a real research table with only observations that can be verified, a shortlist of campaigns with source links and times, and the path to an export bundle plus campaign tracker. State clearly whether an actual recording was available, whether transcription was verified with a real model, and whether any campaign remains suitable after checking its terms.
- Demonstrate a dry run from campaign selection to a conditional payout estimate with fake post URLs and no real external submissions. Record a first pilot targeting three usable clips from one source, with planned publication and submission timing.
